# demo_repo

Repo for Demos

## Overview

`demo_repo` is a lightweight sandbox repository used for demonstrations and
experiments. It intentionally contains no application code, so it can be used
as a clean starting point for showing tools, workflows, and automation without
the noise of an existing project.

## Purpose

- Demonstrate GitHub features such as issues, pull requests, reviews, and Actions.
- Try out automation, bots, and coding agents against a safe, low-risk repository.
- Serve as a scratch space for examples, snippets, and proofs of concept.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/dmsmi/demo_repo.git
   cd demo_repo
   ```

2. Create a branch for your demo:

   ```bash
   git checkout -b my-demo
   ```

3. Add your files, commit, and open a pull request.

## Contributing

Because this repository is used for demos, changes are expected to be small and
self-contained. Keep demo material clearly named and avoid committing secrets,
credentials, or any sensitive data.
